FAQ

Common questions.

Can you add an admin panel to my existing website?

In most cases, yes. After reviewing how your current website is built, we suggest whether to connect a new admin panel to it or rebuild the parts that need it.

Can different team members have different access?

Yes. Roles and permissions can be set up so, for example, staff see bookings while only owners see reports and settings.

Does the admin panel work on mobile?

Yes. Admin panels are designed to work on phones, tablets and computers.
