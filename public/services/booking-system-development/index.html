FAQ

Common questions.

How does the WhatsApp booking work?

The customer picks a service, date and time on your website, and the booking opens in WhatsApp with all details filled in, so you can confirm it in one tap. Fully automatic WhatsApp messages need a WhatsApp Business API provider, which can be set up separately.

Can I see all bookings in one place?

Yes. Bookings can be saved to an admin panel where you can view, confirm, reschedule or cancel them.

Can customers pay while booking?

Yes. Advance or full payment can be added with a payment gateway such as Razorpay or Stripe.
