FAQ

Common questions.

Which payment gateways can you integrate?

Popular options such as Razorpay, Stripe and PayPal can be integrated. The payment provider charges its own transaction fees, which are separate from the website price.

Can I sell to customers in other countries?

Yes. Gateways like Stripe and PayPal accept international cards and multiple currencies, and shipping rules can be set per country.

Can I add and manage products myself?

Yes. With an admin panel you can add products, update prices and stock, and manage orders without any coding.
